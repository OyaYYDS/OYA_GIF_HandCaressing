# 手部挤压 GIF 表情生成器

上传任意图片，自动套用 9 帧手部挤压动画模板，导出透明背景的 112×112 GIF 表情包。纯前端实现，无需服务器，所有处理在本地完成。

![效果预览](效果预览.gif)

---

## 功能特点

- 拖拽或点击上传图片（PNG / JPG / WebP）
- 三档速度模式：快速 / 普通 / 慢速
- 透明背景 GIF 输出（112×112 px）
- 全程本地处理，不上传任何数据

---

## 使用方法

### 方式一：直接打开（推荐）

1. 下载或克隆本仓库
2. 用浏览器打开 `index.html`
3. 上传图片 → 选择速度 → 点击「生成 GIF」→ 下载

> 无需安装任何依赖，无需联网。

### 方式二：本地服务器（解决部分浏览器跨域限制）

```bash
# Python 3
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 参数调整

所有可调参数集中在 `script.js` 顶部的 `CONFIG` 对象中：

| 参数 | 说明 | 默认值 |
|---|---|---|
| `IMAGE_TARGET_OUTPUT_RATIO` | 图片占 GIF 输出尺寸的比例（0~1） | `0.85` |
| `BASE_X` | 图片在合成画布上的水平锚点（像素） | `300` |
| `BASE_Y` | 图片在合成画布上的垂直锚点（像素） | `500` |
| `ANCHOR_X_RATIO` | 水平锚点位置（0=左边缘，0.5=中心，1=右边缘） | `0.5` |
| `ANCHOR_Y_RATIO` | 垂直锚点位置（0=上边缘，1=下边缘） | `1` |
| `SCALE_Y` | 各帧纵向挤压比例曲线（9 个值） | 见代码 |
| `WIDTH_COMPENSATE_FACTOR` | 高度减少时宽度补偿系数 | `0.35` |
| `ALPHA_CUTOFF` | 透明像素阈值，越大边缘越干净 | `80` |

## 已知限制

- **GIF 最快帧率约 50fps（20ms/帧）**：这是所有主流浏览器对 animated GIF 的强制限制，与代码无关。快速模式在 GIF 文件中写入 10ms，但浏览器播放时会自动限制为约 20ms。
- GIF 仅支持二值透明，半透明边缘会被阈值处理，边缘可能略有锯齿。
